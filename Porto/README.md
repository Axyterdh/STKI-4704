# Ridho Anjar — Personal Portfolio

A responsive, dark-themed, bilingual (English / Indonesian) personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, theme, responsive styles, and animations
- `script.js` — language switcher, mobile navigation, and scroll reveal

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository. For a personal site, name it exactly `Axyterdh.github.io`.
2. Extract this project ZIP on your computer.
3. Open the new repository and choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` (upload the files themselves, not an extra enclosing folder).
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
7. Wait a few minutes. Your site should appear at `https://Axyterdh.github.io`.

If you use a repository with another name instead, enable Pages from `Settings → Pages` and your URL will usually be `https://Axyterdh.github.io/REPOSITORY-NAME/`.
